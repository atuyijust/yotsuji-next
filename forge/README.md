# Playlist Forge

ジャンル・国・年代・BPM・エネルギー・ダンサビリティ・明るさ・レーベル・似ているアーティストなどを細かく指定して、条件に合う曲で Spotify のプレイリストを作る Web アプリです。
「ドライブにぴったりな 1980 年代の洋楽」のように、文章で指定することもできます。

## 準備（最初の 1 回だけ）

### 1. Spotify アプリの設定
1. [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) で自分のアプリを開き、**Settings** を開きます。
2. **Redirect URIs** に `https://atuyijust.github.io/yotsuji-next/forge/` を追加して保存します（末尾の `/` も必要です）。ローカルで動かす場合は `http://127.0.0.1:8000/` も追加します。
3. **APIs used** で **Web API** にチェックが入っていることを確認します。
4. **Client ID** をコピーしておきます。

> 2026 年 2 月以降、Development Mode のアプリはアプリ所有者の **Spotify Premium** が必要です。使えるユーザーも最大 5 人までです（自分以外が使う場合は Dashboard の **User Management** に登録します）。

### 2. Last.fm API キー（推奨・無料）
「似ている曲」探しに使います。指定アーティストの代表曲と一緒によく聴かれている曲と、似たアーティストの代表曲を集め、さらに本人の曲の音の傾向（エネルギー・明るさ・BPM など）に近い順に並べます。[last.fm/api/account/create](https://www.last.fm/api/account/create) で作成できます（Callback URL は空欄で構いません）。
キーがなくても動きますが、その場合の似た曲探しは ReccoBeats のおすすめ機能だけになり、精度がかなり下がります。

「似せたい曲」を指定すると、その曲と一緒によく聴かれている曲（Last.fm）を中心に集め、その曲の BPM やエネルギーに近い順に並べます。キーワード欄に「曲名 アーティスト名」を入れた場合も、自動で「似せたい曲」に置き換えます。

### 3. Claude API キー（任意）
文章での指定を Claude（`claude-opus-5-5`）で解釈し、精度を上げます。[Claude Console](https://platform.claude.com/) で発行できます。
キーがなくても、簡易的なルールで文章を解析できます。

## 開く
https://atuyijust.github.io/yotsuji-next/forge/ を開きます（四辻 NEXT のヘッダー「プレイリスト作成 ↗」からも開けます）。
四辻 NEXT に Client ID を入れてあれば、それをそのまま使います。初回は「設定」画面で各 API キーを入力してください。キーはこのブラウザの中にだけ保存されます。

四辻 NEXT のデッキで「似た曲でプレイリスト ↗」を押すと、その曲を「似せたい曲」に入れた状態で開きます。

## 使い方
1. 「Spotify でログイン」を押します。
2. 「文章で指定する」に要望を書いて「条件に変換」を押すか、各項目を直接指定します。
3. 「曲を探す」を押すと、候補の一覧が表示されます。「再生」で Spotify アプリで再生（開いている PC／スマホの Spotify を自動で探します。Premium が必要）、「キュー」で Spotify のキューに追加、⎘ で曲名をコピー、▶ でこのページで試聴、× で外す、↑ で順番を入れ替えられます。キーは DJ 向けの Camelot 表記（例: 8A）です。
   - 再生とキューの権限を追加したため、以前にログインした場合は一度ログアウトしてログインし直してください。
4. プレイリスト名と公開設定（初期値は非公開）を確認して「Spotify に保存」を押します。

### 指定できる条件
| 区分 | 項目 |
|---|---|
| 曲の集め方 | ジャンル、テーマ（ハロウィン・クリスマス・夏など）、似せたい曲、似せたいアーティスト（本人以外 / 本人＋似た人 / 本人のみ）、レーベル、よく聴く曲から |
| 絞り込み | キーワード（曲名・アルバム名に全部の語を含む曲だけ）、リリース時期（年・月）、アーティストの国（含める / 除外する）、曲の長さ、除外するアーティスト、Explicit 除外 |
| サウンド | BPM、エネルギー、ダンサビリティ、明るさ、アコースティック度、インスト度、ライブ感、語り・ラップ度、人気度、調（メジャー / マイナー） |
| 出力 | 曲数、1 アーティストあたりの上限、並び順（盛り上がっていく / BPM 順 / 年代順 など）、探す範囲 |

よく使う条件は「条件を保存」で名前を付けて保存できます。

## しくみ
2024 年 11 月以降、新しく作った Spotify アプリでは Audio Features・Recommendations・Related Artists が使えません。また 2026 年 2 月の変更で、検索の上限が 1 回 10 件になり、人気度とレーベルの項目も削除されました。そこで、次のサービスを組み合わせています。

| 用途 | データ源 |
|---|---|
| 候補の検索（ジャンル・年代・アーティスト・レーベル）、プレイリストの保存 | Spotify Web API |
| BPM などの特徴量、人気度、似た曲のおすすめ | [ReccoBeats](https://reccobeats.com/)（キー不要） |
| 似ているアーティスト | [Last.fm](https://www.last.fm/api) |
| アーティストの出身国 | [Wikidata](https://www.wikidata.org/)（Spotify のアーティスト ID で照合）→ 見つからなければ [MusicBrainz](https://musicbrainz.org/)（1 秒に 1 件の制限があるため時間がかかります）→ かな・ハングルの文字 |
| 年代・ジャンルの定番曲 | Last.fm のタグ（例: 80s, new wave）の上位曲 |
| テーマ（ハロウィンなど）に合う曲 | Last.fm のタグ（halloween, spooky など）の上位曲 ＋ Claude が挙げた定番曲（Spotify で実在を確認） |
| 文章 → 条件の変換 | Claude API（任意） |

## 注意
- ReccoBeats に特徴量が登録されていない曲もあります。「特徴量データがない曲は除く」を外すと、そうした曲も候補に残ります。
- Spotify の `genre:` 検索は精度にばらつきがあります。似せたいアーティストと組み合わせると安定します。
- 取得した特徴量と国の情報はブラウザにキャッシュされ、2 回目以降は速くなります。

## ファイル構成
```
index.html        画面
css/style.css     スタイル
js/app.js         画面の操作
js/engine.js      候補の収集 → 絞り込み → スコア付け → 選曲
js/spotify.js     Spotify の認証（PKCE）と API
js/sources.js     ReccoBeats / Last.fm / MusicBrainz
js/nl.js          文章 → 条件の変換（Claude / 簡易ルール）
js/data.js        ジャンル候補・国・ムードプリセットなど
```
