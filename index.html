はじめに

Mac の四辻 NEXT で 「ライブラリ」→「iPhoneへ設定を渡す」 を押してから、下のボタンを押してください。Macと同じ曲・BPM・タグがそのまま使えます。

うまく読めないときは、ここに長押しで貼り付けてください

1. Spotify接続設定

Spotify Developer Dashboard の自分のアプリで、Redirect URI に次を登録してください：

2. 読み込むプレイリスト

「自分の流れ」は、あなたがプレイリスト内で直前・直後に並べた曲から計算します。Spotifyの仕様上、曲を読めるのは自分が作成（または共同編集）したプレイリストだけです。

3. BPM・キーの取り込み（rekordbox）

rekordboxで「ファイル → ライブラリをxml形式でエクスポート」した XML を読み込むと、曲名＋アーティスト名で照合して BPM・キー・ジャンルを付けます。手入力した値は上書きしません。

3b. BPM・キーの取り込み（Exportify）

exportify.app ↗ で歯車から「Include audio features data」をオンにして書き出した CSV（複数可。「Export All」のZIPは展開してから）を読み込むと、Spotifyの曲IDで直接照合して BPM・キー・ジャンル・エネルギー等を付けます。rekordbox・手入力の値がある曲には触れません。

4. BPM・キーの自動取得（ReccoBeats）

ReccoBeats ↗（無料・登録不要）にSpotifyの曲IDで問い合わせ、BPM・キー・エネルギー等を付けます。登録されていない曲もあります。rekordbox・Exportify・手入力の値がある曲には触れません。見つからなかった曲は30日後にもう一度調べます。

4b. BPMの自動補完（Deezer）

ReccoBeatsでも分からなかった曲のBPMをDeezerで調べて補います（キーは取れません）。rekordbox・手入力の値がある曲には触れません。

5. 端末間で同期（GitHub Gist）

BPM・キー・ジャンル・タグ・重み・履歴に加えて、読み込んだ曲データ（プレイリスト・曲・音の特徴・アーティストのジャンル）も、あなたのGitHubの非公開Gistに保存して、MacとiPhoneで共有します。iPhoneは同じトークンを入れるだけで、Spotifyから読み込まなくてもMacと同じ候補が出ます（再生ボタンを使うときだけSpotifyログインが必要）。
トークンは GitHubの設定 で「Gists: Read and write」だけ付けて発行してください。この端末のブラウザにだけ保存されます。

Client ID と同期のトークンをコピーします。iPhone で四辻 NEXT を開き「設定を貼り付ける」を押すだけで、Macと同じ状態になります（同じApple IDのユニバーサルクリップボード）
